# Compilador Odyssey

## Pré-requisitos
* Compilador C++ (ex: GCC / MinGW)
* CMake
* Ninja (Sistema de build otimizado para maior velocidade)

1. Configurar o projeto e criar a pasta build (utilizando o gerador Ninja):
cmake -G Ninja -B build

2. Compilar o código-fonte:
cmake --build build

3. Realizar Testes e Executar:
.\build\compilador.exe .\01_keywords_basic.cml
